## Brand & Style

This design system delivers a clinical, high-performance technical dossier built around the precision of Steel Azure (`#2E74B5`). Synthesizing an engineering command terminal with elite executive presentation, the system reflects the discipline of competitive software engineering, algorithmic speed, and verified international mastery.

The visual direction merges **Corporate Technical Modern** with **Structural Glassmorphism**. Layouts prioritize dense, readable data presentation, sharp monospaced telemetry, and deliberate hierarchy over purely decorative flourishes. Light mode presents crisp, architectural surfaces reminiscent of pristine engineering briefs and technical whitepapers. The complementary dark mode delivers an immersive, low-strain terminal command center with radiant sapphire accents and luminous gold accolades. Micro-interactions are deliberate and instantaneous (120ms–150ms transitions), mirroring the execution speed of production-grade systems.

## Colors

The color palette centers squarely on **Steel Azure (`#2E74B5`)**, supported by specialized tonal surfaces for both daytime audit clarity and dark command-center immersion.

### Tonal Surface Hierarchy
- **Light Theme**: Built over `#F8F9FC` with a stepped container scale from `#FFFFFF` (container-lowest) down through `#DBE2EB` (container-highest). Interactive states rely on `#2E74B5` fills and `#D2E4FF` soft container washes. Typography is weighted by `#171C22` on surfaces and `#414751` on structural variants.
- **Dark Theme**: Grounds in an obsidian blue-black `#0E141A` with deep-level stepping to `#1B2127` and `#30363D`. The dark primary elevates to `#9ECAFF` to guarantee 7:1+ contrast on midnight panels, while interactive containers retain `#2E74B5`.

### Accolades & Badging Roles
- **Award Gold (`#FBBF24` / `#F59E0B`) & Bronze (`#B45309`)**: Restricted strictly to podium accolades, competition titles (WorldSkills, hackathons), and verified mastery stars. They must never serve as default button states.
- **Teal Accent (`#008080`)**: Secondary technical highlights, benchmark counters, and architecture diagrams.
- **Badge Cyan (`#38BDF8`)**: Monospaced commit hashes, status nodes, and active real-time indicators.

## Typography

The typographic system pairs three specialized typefaces:
- **Headlines (`Sora`)**: Geometric, authoritative, with mathematical proportions that fit high-level engineering titles and structural section anchors.
- **Body (`Inter`)**: Neutral, utilitarian, and engineered for high-density documentation, project dossiers, and technical rationale.
- **Telemetry & Labels (`JetBrains Mono`)**: Dedicated to skills, repository tags, milestone dates, version numbers, and terminal output.

### Application Standards
- `.subheading` applies an uppercase transform with expanded tracking (`0.06em`) for technical section categorization.
- Headings support dual-tint presentation: primary nouns remain in on-surface text (`#171C22` or `#E0E2E8`), accented with secondary Steel Azure keywords.
- Code blocks and skill chips must always render via `JetBrains Mono` with tabular numerals enabled.

## Layout & Spacing

The layout adopts an **architectural hybrid grid** designed for dense engineering CVs, project deep-dives, and competitive dossiers.

### Layout Philosophy
- **Desktop (≥1024px)**: Dual-structure layout featuring an architectural 18rem (`288px`) pinned navigation and profile rail on the left. The remaining workspace flows inside a 12-column responsive fluid grid capped at `content-max-w` (`1200px`), with a 32px (`unit-xl`) gutter.
- **Tablet (768px–1023px)**: Left rail collapses into an elevated horizontal top bar (`height: 4.5rem`), transitioning timelines and metric panels into a balanced 2-column or stacked format with 24px margins.
- **Mobile (<768px)**: Strict single-column stack with 16px (`unit-md`) margins and touch targets calibrated to a minimum 44px height.

### Spacing Rhythm
- Section spacing mandates `unit-3xl` (`4.5rem`) vertical separation between distinct portfolio disciplines.
- Internal card padding follows an asymmetric ratio: `unit-xl` (`2rem`) horizontal with `unit-lg` (`1.5rem`) vertical spacing.
- Compact metadata rows (tags, badges, date stamps) maintain consistent `unit-xs` (`0.5rem`) gaps.

## Elevation & Depth

Visual depth combines **tonal container layering** with **structural glassmorphic borders** rather than thick, opaque drop shadows.

### Light Mode Stack
- **Layer 0 (Canvas)**: `#F8F9FC` baseline base.
- **Layer 1 (Card & Module Surfaces)**: Pure `#FFFFFF` or frosted acrylic (`rgba(255, 255, 255, 0.85)` with `backdrop-filter: blur(12px)`). Encased in a crisp 1px border (`#E3E8F0`). Shadow: `0 4px 16px -4px rgba(23, 28, 34, 0.04)`.
- **Layer 2 (Hover / Active Focus)**: Subtle elevation (`translateY(-2px)`) with a tint-cast shadow: `0 10px 24px -4px rgba(46, 116, 181, 0.12), 0 2px 6px rgba(23, 28, 34, 0.04)`. Border shifts to `#2E74B5`.
- **Layer 3 (Modals & Architecture Previews)**: `#FFFFFF` encased in a deep drop shadow: `0 24px 48px -12px rgba(23, 28, 34, 0.18)` against a soft backdrop scrim (`rgba(14, 20, 26, 0.45)`).

### Dark Mode Stack
- **Layer 0 (Canvas)**: Deep obsidian `#0E141A`.
- **Layer 1 (Card Surfaces)**: `#171D23` with 1px border (`#30363D` or `rgba(255, 255, 255, 0.08)`). Shadow: `0 4px 20px -2px rgba(0, 0, 0, 0.4)`.
- **Layer 2 (Interactive)**: `#1B2127` with a fine Steel Azure edge (`#2E74B5`) and ambient blue glow: `0 0 20px rgba(46, 116, 181, 0.22)`.
- **Layer 3 (Modals / Terminal Shells)**: `#252B32` with an ambient dark rim shadow `0 20px 50px -10px rgba(0, 0, 0, 0.7)`.

## Shapes

The design system operates with **Rounded Level 2** geometry, balancing technical precision with modern enterprise ergonomics:
- **Small Elements (`rounded: 0.5rem / 8px`)**: Form inputs, standard buttons, code badges, terminal controls.
- **Card Containers (`rounded-lg: 1rem / 16px`)**: Milestone containers, metric dashboards, project dossiers.
- **Major Highlights (`rounded-xl: 1.5rem / 24px`)**: Hero bio callouts, major award certificates, master terminal frames.
- **Pills (`rounded-full: 9999px`)**: Status bullets, verification tags, milestone track nodes, medal score markers.

## Components

### 1. Buttons
- **Primary Action**: Solid `#2E74B5` fill with pure `#FFFFFF` text in Light Mode. In Dark Mode, transitions to `#9ECAFF` fill with `#003259` bold text for immediate visibility. Border radius: `0.5rem`. Hover applies a 2px lift and an ambient primary glow.
- **Secondary / Ghost**: Light mode uses `#EBF0F6` surface with `#2E74B5` text. Dark mode uses `#252B32` with `#9ECAFF` text.
- **Outline Action**: Transparent body with a 1.5px border (`#2E74B5` in light, `#414751` in dark). On hover, dark mode border activates to `#9ECAFF`.

### 2. Tech Chips & Status Badges
- **Tech Stack Chips**: Set in `JetBrains Mono` (12px), padded 4px 10px. Light mode uses `#F1F4F9` fill with `#414751` text and `#E3E8F0` border. Dark mode uses `#171D23` fill with `#C1C7D3` text and `#30363D` border.
- **Accolade & Medal Badges**: High-prestige indicators. Light mode uses an amber tint (`rgba(217, 119, 6, 0.1)`) with `#B45309` text. Dark mode shifts to dark amber base with luminous `#FBBF24` text and a subtle 1px `#F59E0B` border.
- **Live Status Pill**: Outer 8px ping indicator with a continuous pulse glow; `#008080` in light, `#38BDF8` in dark.

### 3. Cards & Timeline Nodes
- **Dossier Card**: Encased in Layer 1 styling. Card header displays institution and project title (`Sora`, `headline-sm`), with monospaced timeline range aligned to the right edge. Body items use crisp indentations with Steel Azure chevron indicators.
- **Timeline Track**: Continuous 2px spine in `#E3E8F0` (light) or `#30363D` (dark). Standard milestone nodes render as concentric rings (16px outer shell with 6px Steel Azure center). International award nodes substitute a glowing gold star or bronze laurel indicator.

### 4. Terminal & Code Shell
- Enclosed in `#090D16` across both color modes with classic three-dot window anchors (macOS-style 10px dots: `#EF4444`, `#F59E0B`, `#10B981`). Syntax highlights utilize `#38BDF8` (properties), `#9ECAFF` (functions), and `#FBBF24` (strings/constants).

### 5. Form Inputs & Filter Triggers
- Height: 42px. Filled with `surface-container-low`, framed with 1px `outline-variant`. On active focus, applies a 2px ring in Steel Azure (`#2E74B5` in light, `#9ECAFF` in dark). Monospaced keyboard accelerators (`⌘K`) dock flush right.
